# 中文预训练模型说明

## BERT-base-Chinese 模型

### 模型简介
`bert-base-chinese` 是 Hugging Face 提供的基于中文文本预训练的 BERT 模型，采用传统 BERT 架构并针对中文文本进行了优化。

### 主要特点
| 特性 | 说明 |
|------|------|
| **架构** | 标准 BERT-base 架构 |
| **层数** | 12层 |
| **隐藏层维度** | 768 |
| **注意力头数** | 12 |
| **词汇表大小** | 约21,128个中文字符和词汇 |
| **预训练数据** | 中文维基百科及其他中文网页内容 |
| **最大序列长度** | 512 tokens |

## GPT2-Chinese-CLUEcorpussmall 模型

### 模型简介
`gpt2-chinese-cluecorpussmall` 是基于 GPT-2 架构的中文生成模型，使用 CLUE 语料库训练。

### 主要特点
| 特性 | 说明 |
|------|------|
| **架构** | GPT-2 small 架构 |
| **层数** | 12层 |
| **隐藏层维度** | 768 |
| **注意力头数** | 12 |
| **词汇表** | 中文优化词汇表 |
| **预训练数据** | CLUE 语料库 |
| **最大序列长度** | 1024 tokens |
